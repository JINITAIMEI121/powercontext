它是怎么工作的

  1. 全文候选：MATCH … AGAINST 命中关键词与术语。
  2. 语义候选：l2_distance 在向量列上找相近主题。
  3. RRF 融合：两路排名归一后取交集，减少单路偏差。
  4. 引用回查：结果保留笔记 ID，可回到原始正文核对。

关于 NoteSeek

NoteSeek 是为学习和科研场景做的本地笔记知识库：用嵌入式 seekdb 同时维护全文索引与向量列， 不用部署数据库服务，也不把笔记发给在线模型。当前页面是 Qoder Sites 静态演示； 在本地运行 python app.py 即可读写真实 seekdb 实例。
